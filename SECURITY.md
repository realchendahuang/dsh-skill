# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `dsh-skill`, please do not report it through public GitHub issues.

Instead, please send an email to `realchendahuang@gmail.com` with:
- A description of the issue.
- Steps to reproduce or a minimal proof of concept.
- Potential impact.

We will acknowledge receipt within 48 hours and work with you to resolve the issue promptly before public disclosure.
